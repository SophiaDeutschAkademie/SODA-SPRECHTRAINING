# SODA SPRECHTRAINING

Sophia Deutsch Akademie의 독일어 대화 말하기 훈련 웹앱입니다. 표지 → 레벨 선택(A1–C1) → 대화 목록 → 대화 화면으로 구성돼요.

## 대화 화면 기능

- **내 역할**: 나는 A 또는 B를 고르면 내 줄에 녹음 버튼이 나타나요.
- **가리기**: A·B 한쪽 또는 모두를 가려서 외운 대로 말해 볼 수 있어요. 가려진 줄은 눌러서 볼 수 있어요.
- **해석 보기/가리기**: 한국어 해석을 켜고 끌 수 있어요.
- **단계별 연습**: 상대 줄은 독일어 음성으로 들려주고, 내 줄은 가린 채로 차례를 기다려요. 말해 본 뒤 '다음'을 누르면 다음 줄로 넘어가요.
- **녹음 비교**: 내 줄을 녹음하고, '내 녹음 듣기'와 '원문 듣기'를 번갈아 들을 수 있어요.
- **Redemittel**: 대화에 쓰인 표현을 기능별로 묶었어요. 표현을 누르면 독일어로 들을 수 있어요.

녹음은 메모리에만 보관되므로 화면을 떠나면 사라져요. 독일어 음성은 기기(브라우저)에 설치된 독일어 음성을 사용해요. 독일어 음성이 없는 기기에서는 음성 듣기가 안 될 수 있어요.

## GitHub Pages로 배포하기

1. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정하고 Save를 누릅니다.
2. 1~2분 뒤 `https://sophiadeutschakademie.github.io/저장소이름/` 주소로 접속됩니다.

녹음 기능은 HTTPS 주소에서만 작동하므로 GitHub Pages 주소로 여세요.

`.nojekyll` 파일은 숨김 파일이라 폴더에서 안 보일 수 있어요. 지우지 마세요.

## 구조

- `index.html` : 앱 화면 (표지, 레벨 선택, 목록, 대화 화면을 한 페이지 안에서 전환)
- `assets/` : 화면 스타일(`app.css`, `dialog.css`), 동작(`app.js`), 로고, 아이콘, 글꼴
- `data/` : 대화문 데이터. 레벨별 파일 `a1.js` … `c1.js`, 특별 챕터 `mz.js` (각 6개)

## 대화 고치기·추가하기

`data/`의 레벨별 파일(예: `a1.js`)에서 대화를 고칩니다.

| 항목 | 내용 |
|---|---|
| `no`, `lv` | 번호, 레벨 (예: `1`, `'A1'`) |
| `title`, `titleKo`, `type`, `typeKo`, `intro` | 독일어 제목, 한국어 제목, 대화 종류(독·한), 목록 설명 |
| `umg` | (MZ 챕터) 구어체 풀이. `de`(대화에 나오는 그대로), `t`(나오는 줄 번호, 1부터. 여러 줄이면 배열), `ko`, `std`(표준 독일어), `reg`(구어·축약·불변화사·추임새·감탄·관용구) |
| `focus` | 목록 카드에 보이는 학습 포인트 태그 (3개까지 표시) |
| `roles` | 역할 이름 `{ A: '...', B: '...' }` |
| `turns` | 발화 목록. `r`(A 또는 B), `de`(독일어), `ko`(해석) |
| `redemittel` | 표현 묶음. `group`(기능 이름), `items`(`de`, `ko`) |

대화를 더 만들 때는 같은 레벨 배열 끝에 `{ ... }`를 쉼표로 이어 붙이고 `no`를 다음 번호로 정하면 됩니다. 목록, 이전·다음 대화 이동에 자동으로 나타나요. 한 레벨의 `no`는 1, 2, 3…처럼 겹치지 않게 쓰세요(주소는 `#/a1/02` 형식).

## MZ 챕터

독일 사람들이 일상에서 실제로 쓰는 구어체(Umgangssprache)를 익히는 특별 챕터예요(`data/mz.js`). 은어와 유행어는 쓰지 않아요. 대화 속 구어체 표현은 노란 밑줄로 표시되고, 대화 아래 ‘Umgangssprache’에 뜻과 표준 독일어 표현이 나와요. 표시는 ‘구어체 표시 끄기’로 숨길 수 있어요.
